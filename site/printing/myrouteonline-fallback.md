# MyRouteOnline fallback
{: .no_toc }

**Who:** coordinator, route planner.
**When:** only if the app can't be used for routing this season.

1. TOC
{:toc}

{: .why }
MyRouteOnline is how the committee routed in 2025, and it stays the backup plan for 2026. If the app's routes can't be used, you can still use everything else the app did (imported sign-ups, checked addresses, cleaned letters) and hand MyRouteOnline a clean address list instead of the raw export.

## Export the address list

Either:

- **Print center** ▸ "Other printouts and exports" ▸ **MyRouteOnline CSV**, or
- **Families** ▸ **Fallback CSV**.

Both save the same file, `MyRouteOnline.csv`, with two columns:

| Title | Address |
|---|---|
| 26001 | 112 Maple Ave, Unit 101, Pasadena, CA, 91101 |
| 26002 | 124 Oak Ave, Pasadena, CA, 91101 |

- "Title" is the Entry ID, so each stop in MyRouteOnline links back to a letter.
- Only home-delivery families who aren't cancelled are included.
- No names, phone numbers or letters are in the file.

{: .warning }
The file isn't encrypted. Delete it once it's uploaded.

## Plan in MyRouteOnline

As in 2025, roughly:

1. Sign in to the club's MyRouteOnline account. Keep the login in the club's password manager, not in an email.
2. Import `MyRouteOnline.csv` as the address list.
3. Set the start and end to the North Pole, the start time (4:30 PM), and a service time per stop. 2025 used 10 minutes; the app's own estimate averages more because of apartments, gates and big families.
4. Set the number of routes and generate them.
5. Print or export each route.

{: .note }
**Draft:** MyRouteOnline's screens and pricing change from year to year; check the steps against the live site before relying on them. Its pricing is per unique address, so a full season needs enough address credits.

## What you lose

The app's team packets, labels and reprint tracking all depend on the app's own routes. With MyRouteOnline routes:

- letters and labels don't know the route and stop, so they must be sorted by hand again;
- MyRouteOnline's route sheets don't show gate codes or units;
- late changes aren't tracked against printed packets.

Use this only if you have to.
