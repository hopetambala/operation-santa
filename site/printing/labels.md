# Bag labels and the alignment test
{: .no_toc }

**Who:** print lead.
**When:** before the main print run.

1. TOC
{:toc}

{: .why }
In 2025 the labels came from a separate Word merge and carried only the Entry ID and family name, with no route or stop. Matching bags to letters and routes was done by hand. Now each team packet ends with its own labels, one per bag, each saying which route and stop it belongs to.

## What a label says

- **Route 3 – Stop 5** in large type
- Entry ID and "Bag 1 of 2"
- Family name
- Each child in the bag: first name, age and first choice
- Optional: the street address

Children are split into bags by Settings ▸ "Children per bag" (3 by default). A family held by the coordinator gets labels saying "See coordinator" instead of the children's details.

## Choose the label sheet

In **Print center**, under the banner:

1. "Labels": choose **Avery 5163 · 4×2 in · 10/sheet** (the default, with room for every child) or **Avery 5160 · 1×2⅝ in · 30/sheet** (address-label size, shorter text).
2. "Street address on labels": tick it to add the address. Leave it off unless the committee wants it: it puts a family's address on a bag that might be left in a car.

## Run the alignment test first

1. Click **Alignment test page**. Save the PDF (`Label alignment test 5163.pdf`) and open it.
2. Print it on **plain paper**, at **100% / actual size**. Turn off "fit to page" or "scale to fit" in the print box.
3. Hold the printed page against a sheet of labels, up to a window or a light. Each box ("Avery 5163 · slot 1", and so on) should sit inside a label.
4. If the boxes are off, check the printer's scale and paper-size settings (US Letter) and try again before using label sheets.

![The label alignment test page for Avery 5163, with ten numbered slots]({{ '/assets/images/label-alignment-test.png' | relative_url }})

## Start on a part-used sheet

If the first few labels on a sheet are already used, set "Start at slot" to the first free label. Slots count left to right, top to bottom: 1 to 10 on Avery 5163, 1 to 30 on Avery 5160. The setting applies to the first label page of **every** route in the next PDF, so use it for a single route's packet, and set it back to 1 afterwards.

## Printing the labels

The labels print at the end of each route's packet, so print the team packets with label sheets loaded for those pages, or print the label pages separately from the PDF using the printer's page range. The pickup event packet ends with its own labels, titled "Pickup – #26014".
