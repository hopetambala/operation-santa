# Install and update
{: .no_toc }

**Who:** coordinator, route planners, letter cleaners, print lead. Santa team leads don't need the app.
**When:** before November 1, and again whenever a new version is offered (never December 20–26).

1. TOC
{:toc}

{: .why }
In 2025 the routing tool was a website with paid accounts whose logins were passed around in emails and a PDF. The letters depended on a Word template and a spreadsheet saved on one person's laptop. Operation Santa is a normal desktop app instead: anyone on the committee can install it, it needs no shared logins, and the season's data stays in one encrypted file on the coordinator's computer.

## Mac

{: .note }
**Draft:** the committee hasn't yet confirmed which Mac install the volunteers will use for 2026: the downloadable DMG, TestFlight, or both. Both are described here.

### From the download (DMG)

1. Open the [latest release](https://github.com/hopetambala/operation-santa/releases/latest) page.
2. Under **Assets**, click the file ending in `.dmg`.
3. Open the downloaded file. A window shows the Operation Santa icon and an Applications folder.
4. Drag **Operation Santa** onto **Applications**.
5. Open **Applications** and double-click **Operation Santa**. If the Mac asks whether you're sure you want to open an app downloaded from the internet, click **Open**.

<!-- screenshot: the DMG window with the app icon and the Applications folder -->

### From TestFlight

1. Install **TestFlight** from the Mac App Store.
2. Open the invitation email or link the coordinator sent, and click **Accept** or **View in TestFlight**.
3. In TestFlight, click **Install** next to Operation Santa.

TestFlight updates the app for you. TestFlight builds expire after 90 days, so the coordinator sends a fresh build before the season if needed.

## Windows

1. Open the [latest release](https://github.com/hopetambala/operation-santa/releases/latest) page.
2. Under **Assets**, click the file ending in `-setup.exe`.
3. Open the downloaded file.
4. Windows shows a blue box saying it "protected your PC". This is expected: the 2026 Windows installer isn't signed. Click **More info**, then **Run anyway**.
5. Follow the installer. It installs for your Windows account only, so it doesn't ask for an administrator password.

<!-- screenshot: the Windows SmartScreen box with "More info" and "Run anyway" -->

## The first time you open it

The app opens on a **demo season** with fictional families, and the top right of the window says "Demo · synthetic data". Explore freely; nothing there is real. When you're ready for real sign-ups, [create a season file]({{ '/start-here/season-file/' | relative_url }}).

## Updates

Downloaded copies (the DMG and Windows) check for a new version each time they open.

1. When one is ready, a banner says "Version … is ready." with a short note on what changed.
2. Click **Install and restart** to update now. Your season is saved first, and the app reopens by itself.
3. Or click **Later**. The banner comes back the next time you open the app.

To check by hand: Settings ▸ **Check for updates**. If there's nothing new, the app says "You have the latest version."

{: .warning }
**No updates during delivery week.** From December 20 to December 26 the app never offers an update, and **Check for updates** says "Updates are paused until December 27 so nothing changes during delivery week." The version you print with is the version you deliver with.

TestFlight and App Store copies don't show this banner. TestFlight updates them, and **Check for updates** always says you have the latest version.
